# 🐲 Dragon Ball API - Proyecto Django

Aplicación web para visualizar personajes de Dragon Ball utilizando la API de Dragon Ball.

## 🚀 Características

- ✅ Listado de personajes de Dragon Ball
- ✅ Búsqueda por nombre
- ✅ Paginación
- ✅ Modal con detalles de cada personaje
- ✅ Diseño responsive
- ✅ Efectos visuales y animaciones

## 🛠️ Tecnologías

- Django
- Bootstrap 5
- JavaScript (Vanilla)
- Dragon Ball API

## 📦 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/TU_USUARIO/dragronball2.git
cd dragronball2
```

2. Crea un entorno virtual:
```bash
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate
```

3. Instala las dependencias:
```bash
pip install django
```

4. Ejecuta el servidor:
```bash
python manage.py runserver
```

5. Abre tu navegador en: `http://127.0.0.1:8000/`
